# DNS-AI (.NET / Avalonia 12)

Клиент шифрованного DNS для Windows, переписанный на современном стеке **C# / .NET** с графическим интерфейсом на **Avalonia UI 12**.

Оригинал: [confeden/DNS-AI](https://github.com/confeden/DNS-AI.git)

---

## Возможности

- **Локальный DoH-резолвер**: поднимает прозрачный DNS-прокси на `127.0.0.1:53` (UDP и TCP).
- **RFC 8484 DoH клиент**: передает запросы по защищенному протоколу HTTPS (HTTP/2) на узлы `dns.dns-ai.ru`.
- **Защита от циклов резолва (Bootstrap Loop Prevention)**: прямое TCP/TLS подключение к пулу IP-адресов узлов (`192.144.59.14`, `186.246.49.127`, `94.232.43.149`) в обход системного DNS.
- **Управление сетевыми адаптерами**:
  - Автоматический поиск активных физических интерфейсов (Wi-Fi, Ethernet).
  - Игнорирование виртуальных интерфейсов (Docker, WSL, Hyper-V) и туннелей VPN.
  - Сохранение резервной копии (бэкапа) исходного состояния (DHCP или статические адреса).
  - Корректное восстановление при выключении защиты или закрытии приложения.
- **Интерфейс на Avalonia 12**:
  - Современный дизайн Fluent UI в темной теме.
  - Большой переключатель защиты.
  - Мониторинг задержки (пинг), счетчик обработанных запросов, активный узел.
  - Список обнаруженных сетевых адаптеров.
  - Иконка в системном трее (TrayIcon) с быстрым доступом и выходом.
  - Быстрая очистка кэша DNS (`ipconfig /flushdns`).

## Запуск в режиме разработки

Для запуска требуется .NET SDK (8.0 или новее):

```powershell
dotnet run --project src/DnsAi.App/DnsAi.App.csproj
```

> **Примечание**: для изменения сетевых настроек адаптера требуются права администратора. Запускайте терминал от имени администратора, либо запускайте скомпилированный `.exe` (он автоматически запросит повышение UAC).

---

## Сборка в один автономный `.exe`

Сборка одного исполняемого файла, не требующего установленного .NET на целевом компьютере:

```powershell
dotnet publish src/DnsAi.App/DnsAi.App.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o ./publish
```

Готовый файл `dns-ai.exe` будет находиться в папке `publish/`.

---

## Переключение на .NET 10

Проект изначально спроектирован с полной совместимостью с **.NET 10**. 
В `src/DnsAi.App/DnsAi.App.csproj` по умолчанию настроена сборка под текущий установленный SDK:

- Чтобы собрать под .NET 10 (после установки .NET 10 SDK), достаточно передать флаг:
  ```powershell
  dotnet build -p:TargetNet10=true
  ```
  или изменить `<TargetFramework>net8.0-windows</TargetFramework>` на `net10.0-windows`.
